## 📝 Контент-маркетинг (привлечение пользователей)

> Отдельный пул задач не про код — про привлечение трафика и SEO через статьи о казахстанском авторынке. Цель: использовать наши же данные (Neon DB) для получения уникальных инсайтов, которых нет у конкурентов.

### Идеи статей (черновики тем)

- [ ] **Электро vs бензин в РК** — сравнение TCO (total cost of ownership) на 5 лет: Tesla / BYD / Zeekr vs Camry / Sportage. Цены наши, расход топлива/энергии — отдельные источники, амортизация — из price_history.
- [ ] **Китайские авто на рынке Казахстана: полный гайд** — какие бренды реально продаются (Chery / Geely / Haval / BYD / Changan), динамика средней цены за 90/180/365 дней по нашим данным, "медиана дней до продажи".
- [ ] **Топ-10 моделей по падению цены за полгода** — drop-leaders по `/api/v1/analytics/profitability`, объяснение причин (новый рестайлинг, проблемы с ТО, тренды).
- [ ] **Почему Toyota держит цену лучше всех** — статистика volatility по брендам. Наша price_history идеально подходит. Заодно сравнить Land Cruiser 100 / 200 / Prado.
- [ ] **Lada / ВАЗ: реальный спрос в РК после 2024** — рассказ как российские модели чувствуют себя на казахстанском вторичке. Brand-level анализ с числами.
- [ ] **Когда лучше покупать машину: сезонность цен** — гистограмма средних цен по месяцам / сезонам.
- [ ] **Автомобили до 5 млн ₸: лучшие варианты по объёму предложения** — bucket-анализ.
- [ ] **Премиум-сегмент в KZ: BMW vs Mercedes vs Lexus** — кто продаётся быстрее, у кого больше дисконт от прайса.
- [ ] **Региональные различия цен (Алматы vs Астана vs Шымкент)** — с heatmap (у нас уже есть KZMap-компонент).
- [ ] **Растаможенные vs не растаможенные: сколько экономит "евраху"?** — сравнение через title-фильтр по ключевым словам ("не растамож").
- [ ] **Автомобиль за 1 миллион тенге: что реально можно купить в 2026** — практический гайд с примерами.
